Instalar como aplicación

Abrí este sitio desde Safari y tocá Compartir → Agregar a inicio. Necesitás el enlace HTTPS publicado, no un archivo local.

El modelo local requiere descargar cientos de MB la primera vez. Algunos iPhone pueden quedarse sin memoria o no admitir el motor. No hay API paga configurada ni acceso a tus otras aplicaciones.
