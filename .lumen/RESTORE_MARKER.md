# LUMEN Command Center Restore

Restoration branch for rebuilding full command-center parity from the historical Railway-era modules onto the zero-cost Cloudflare/D1 architecture.

Principles:
- preserve current D1 state and zero-cost runtime;
- restore information density and historical module coverage;
- do not fabricate unavailable historical data;
- keep external actions gated until explicitly approved;
- deploy only after validation.
