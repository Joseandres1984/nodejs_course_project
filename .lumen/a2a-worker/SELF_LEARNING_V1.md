# LUMEN Self-Learning v1

LUMEN does not rewrite its own code. Its autonomous learning is policy adaptation over verified operational evidence.

Loop:

1. Observe the current funnel state and bottleneck.
2. Execute only actions already permitted by the authority policy.
3. Measure verified funnel/revenue movement.
4. Write a postmortem.
5. Convert the postmortem into a bounded learning signal.
6. Nudge tactic preference scores with a confidence-weighted learning rate.
7. Increase exploration when verified stagnation persists.
8. Choose a reversible zero-spend experiment for the next comparable context.
9. Keep financial, contractual, paid-media, connector and production-deploy actions human-gated.

Promotion never means causal certainty: attribution remains observational until repeated evidence supports the same result.
